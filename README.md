# Nigerian Food API

Learning DevOps by building a real application.

## Goal
Understand why containers matter and how they solve the "works on my machine" problem.

## Week 1: The Developer's Nightmare

### Problem
- App works locally on Mac/Linux
- Deployment to production fails
- Environment inconsistency

### Solution
- Use containers to package app + dependencies
- Run identically everywhere

- `/src` - Application code
